# MgcProject
# Lupus in JavaFX

Implementazione del gioco da tavolo "Lupus in Tabula" come applicazione desktop Java.
I giocatori ricevono ruoli segreti e si alternano in fasi notturne e diurne fino alla vittoria di Lupi o Umani.
Il sistema salva i profili dei giocatori con XP e livelli tra una partita e l'altra.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25
- Gradle

### Istruzioni

```bash
git clone <https://github.com/alessia002/MgcProject.git>
cd MgcProject
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```
